# Data

## `raw/Sleep_health_and_lifestyle_dataset.csv`

Source: [Sleep Health and Lifestyle Dataset](https://www.kaggle.com/datasets/uom190346a/sleep-health-and-lifestyle-dataset) (Kaggle, public domain). 374 rows, 13 columns. Not modified — the pipeline reads this file directly.

| Column | Type | Notes |
|---|---|---|
| `Person ID` | int | Row identifier, dropped before modeling |
| `Gender` | categorical | Male / Female |
| `Age` | numeric | Years |
| `Occupation` | categorical | 11 levels; several are rare (e.g. `Manager` n=1) — see main README "Limitations & Future Work" |
| `Sleep Duration` | numeric | Hours |
| `Quality of Sleep` | numeric | Self-reported, 1-10 |
| `Physical Activity Level` | numeric | Minutes/day |
| `Stress Level` | numeric | Self-reported, 1-10 |
| `BMI Category` | categorical | Raw data has 4 levels (`Normal`, `Normal Weight`, `Overweight`, `Obese`); the pipeline merges `Normal Weight` into `Normal` — see `preprocessing.merge_bmi_categories` |
| `Blood Pressure` | string | `"systolic/diastolic"`, split into `Systolic_BP` / `Diastolic_BP` |
| `Heart Rate` | numeric | bpm |
| `Daily Steps` | numeric | Steps/day |
| `Sleep Disorder` | categorical (target) | `None` / `Insomnia` / `Sleep Apnea` — encoded to `SleepDisorder_3class` (0/1/2) |

No missing values in the raw file.

## `processed/`

Generated by `sleep_disorder.main`; not committed to git (see `.gitignore`). Regenerate with:

```bash
python -m sleep_disorder.main
```

- `sleep_cleaned.csv` — output of `preprocessing.clean_dataset`: blood pressure split, target label-encoded, BMI categories merged. Categorical columns are still raw strings; one-hot encoding happens inside each model pipeline (train-fold-only fit), not here.
